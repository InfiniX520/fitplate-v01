# 运行与复现

需要 Linux 或 WSL、Node 24.10 以上、Python 3.12、pnpm，以及已安装和构建的 Agnes Harness。AGH 使用技术说明中的固定提交。

在本项目根目录，按源码 README 安装依赖、配置 DeepSeek API Key、绑定新目录路径并启动服务。详细命令均在源码 README 中。源码包含已构建前端、锁文件和复现脚本；AGH、依赖目录、账号和密钥需另行准备。

## 界面操作

打开启动脚本提供的地址，创建会话并载入 `.agh/skills/fitplate-design/SKILL.md`。在 FitPlate 面板中选择示例或填写安装要求，检查条件后发送。缺失项补齐后，点击“确认条件，开始设计”，按 AGH 权限卡提示授权工具调用。

任务完成后可查看 G01–G08 报告、切换候选、比较版本和下载 STEP、STL、报告。未发送的输入按浏览器和会话保存七天；刷新只恢复填写值，需要重新检查确认。

## 自动化运行

将 `examples/reproduction/normal.json` 等输入文件复制到源码目录。不要将含参考结果的整个测试材料目录设为模型工作区。设置 `AGH_SOURCE_ROOT` 后，在源码根目录执行：

```bash
"$AGH_SOURCE_ROOT/node_modules/.bin/tsx" scripts/reproduction/freeze-native-reproduction.mjs --input "$PWD/request.json" --out "$PWD/protocol.json"
"$AGH_SOURCE_ROOT/node_modules/.bin/tsx" scripts/reproduction/native-reproduction.mjs --execute --protocol "$PWD/protocol.json" --input "$PWD/request.json"
```

脚本按保存的输入运行，候选位置由模型选择；结果不一定与材料中已观察到的坐标相同。默认每例 300 秒，每个任务修订最多四个候选。

## 产物检查与离线重建

在实际运行输出路径上执行：

```bash
PYTHONPATH=geometry .venv/bin/python scripts/verify-cad.py /absolute/path/candidate --json
PYTHONPATH=geometry .venv/bin/python scripts/verify-bundle.py /absolute/path/export --json
PYTHONPATH=geometry .venv/bin/python scripts/reproduce-candidate.py --input-dir /absolute/path/frozen-input --design /absolute/path/design.json --out /absolute/path/new-rebuild
```

输入、设计和报告须来自同一任务修订。重建输出目录应为新目录。STEP 导出元数据可能变化，重建时比较几何测量和要求，而不是只比较 STEP 字节。离线重建不调用模型。

AGH 的固定版本最多登记 64 个 Skill 根目录；长期批量建立新工作区可能达到上限。可保留旧记录，另建 AGH 配置目录和端口继续使用。自动化浏览器依赖及服务停止命令见源码 README。
