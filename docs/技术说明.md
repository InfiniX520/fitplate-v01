# 技术说明

FitPlate 以 Agnes Harness（AGH）管理会话、附件、权限、工具调用和运行记录。安装要求通过分步表单输入，插件将确认后的条件保存为任务；模型调用 Python/CadQuery 工具生成候选，检查程序重新读取 STEP 文件，再将结果返回模型和三维面板。

## 设计与检查

任务保存板尺寸、固定孔位、环境和设计许可。模型只在许可范围内选取候选位置。需求检查、用户确认、建模、验证和导出分别由 `fitplate_propose_constraints`、`fitplate_commit_task`、`fitplate_build_candidate`、`fitplate_validate_candidate` 和 `fitplate_export_package` 等工具完成。

修改方案会生成新版本，并记录 `parent_candidate_id`。任务修订号、候选、STEP 和报告保持对应；导出使用当前候选的有效报告。失败、临界或缺少报告的版本不能作为通过件交付。

G01–G08 检查涉及实体有效性、板尺寸与姿态、底座孔、设备孔组与位置、孔边材料余量、干涉与自由间隙、固定条件和导出一致性。G06 的最小自由间隙对象对取 `measured.minimum_free_clearance_pair`，`objects` 仅表示检查范围。允许的支撑接触与自由间隙分开判断。

建模和检查由不同进程执行，但使用同一 CadQuery/OCCT 几何内核。三维面板使用实际 STEP 生成的网格，检查结论以报告中的测量结果为准。

## 模型和软件

产品流程使用官方 DeepSeek API，模型配置 ID 为 `deepseek-flash`（项目中称 DS-v4.1），思考档位 `high`，上下文预算 1048576，输出上限 16384。接口为 `https://api.deepseek.com/v1`。复现时需自行配置 API Key。

开发使用 Claude Code 调用 GLM5.3（配置 ID `glm-5.3[1M]`），以及 Codex 中的 Astra、6.1Sol 辅助编码、审查和修复。视频中文旁白由 Microsoft Edge 语音 `zh-CN-XiaoxiaoNeural` 合成。

几何处理使用 CadQuery 2.8.0 / OCP，三维显示使用 three.js，界面使用 React。环境为 Linux/WSL、Node 24 和 Python 3.12。AGH 固定提交为 `cde816b88c737b9fd04e7ef55b899e7b4cd55eb7`，未修改其核心代码。

## 数据与权限

Banner Q20PD 的设备尺寸来自 Banner Q20 手册 127816；坐标推导、用户填写值和自设环境分别记录来源。许可和阈值属于任务条件，不能通过修改这些条件来消除检查失败。

产品工作区限制通用写入、shell、联网和代码执行，模型通过 FitPlate 工具完成设计。普通只读查询仍遵循 AGH 权限配置，这些限制不构成完整文件系统隔离。

第三方组件和许可列在源码的 `THIRD_PARTY.md`、`LICENSE` 及依赖锁文件中。文档整理没有改变程序、模型输入或既有测试产物。
