# FitPlate：安装与运行

FitPlate在Agnes Harness原生界面中整理安装需求，确认冻结后生成转接板，检查实际STEP并按反馈修订。支持一个Banner Q20PD设备卡与有限中文约束。环境和要求按表单来源记录；当前只有软件几何验证，没有实物装配、强度、制造公差或性能实测。源码包不含密钥、运行产物、测试参考答案或监督预期。

## 环境与解压

需要Linux/WSL、Node24.10+、Python3.12+、pnpm、已按其文档安装依赖/构建的Agnes Harness源码树，提交固定为cde816b88c737b9fd04e7ef55b899e7b4cd55eb7。AGH 需单独安装，本包不包含 AGH。

```bash
mkdir fitplate-repro
cd fitplate-repro
unzip /absolute/path/fitplate-source.zip
pnpm install --frozen-lockfile
python3.12 -m venv .venv
.venv/bin/pip install -r geometry/requirements.lock.txt
./node_modules/.bin/tsc -p tsconfig.client.json --noEmit
```

Node/Python依赖装在新目录，不链接开发项目的node_modules或.venv。包内保留当前构建的插件JS/CSS/map与源码声明，可直接安装；主流程不重新构建。可选node scripts/build-client.mjs会重新生成资产，需重新记录包身份并安装。

## 配置 DeepSeek 与项目路径

按实际AGH路径替换下方第一行。必须先创建新配置，再启动服务；配置器拒绝已有home。下列 AGH 脚本使用 AGH 安装目录中的 tsx（其公开入口仍引用TS源码），配置器使用 tsx 运行。

```bash
export AGH_SOURCE_ROOT=/absolute/path/agnes-harness
export FITPLATE_SCOPE=competition
export AGH_HOME="$PWD/.agh-home-repro"
export AGNES_PROFILE=local-dev
export AGNES_WEB_ORIGIN=http://127.0.0.1:4391
read -r -s -p 'Official DeepSeek key: ' FITPLATE_OFFICIAL_DS_KEY
export FITPLATE_OFFICIAL_DS_KEY
"$AGH_SOURCE_ROOT/node_modules/.bin/tsx" scripts/reproduction/configure-official-ds-1m.mjs --project-root "$PWD" --agh-source-root "$AGH_SOURCE_ROOT" --home "$AGH_HOME" --origin "$AGNES_WEB_ORIGIN"
"$AGH_SOURCE_ROOT/node_modules/.bin/tsx" scripts/reproduction/configure-official-ds-1m.mjs --project-root "$PWD" --agh-source-root "$AGH_SOURCE_ROOT" --home "$AGH_HOME" --origin "$AGNES_WEB_ORIGIN" --execute
unset FITPLATE_OFFICIAL_DS_KEY
node scripts/reproduction/bind-fresh-runtime.mjs --project-root "$PWD"
node scripts/reproduction/bind-fresh-runtime.mjs --project-root "$PWD" --execute
"$AGH_SOURCE_ROOT/node_modules/.bin/tsx" scripts/agh/start.mjs
"$AGH_SOURCE_ROOT/node_modules/.bin/tsx" scripts/agh/package-fitplate.mjs
"$AGH_SOURCE_ROOT/node_modules/.bin/tsx" scripts/agh/web.mjs start
```

配置器默认dry-run，不写文件、不发网络/模型请求。execute只用环境变量中的用户官方key保存到新配置目录的 secrets 子目录，并由 profile 引用；不读取开发settings。产品模型使用DeepSeek API（https://api.deepseek.com/v1），模型ID deepseek-flash、high、1048576上下文预算、16384输出上限。价格为未计价占位，不能据此认为免费。模型名称和档位按配置记录，不宣称所有请求均使用满上下文。

路径绑定脚本只改新目录plugin/package.json中geometryRoot和pythonPath；源代码和构建资产保持不变。由于部署配置位于包manifest，**新目录安装包哈希会变化**，以package-fitplate的实际inspect/trust/install结果为准，不表示与开发实例二进制完全相同。预算和其余配置保持原值，不手写Host configuration.json。

固定AGH版本的Skill日志最多登记64个根目录（包含内置根和不同工作区的根）。长期批量创建新工作区，达到上限后可能在模型请求前出现`skills.refresh / RESOURCE_RECONCILE_FAILED`；这不等于模型API故障。在已登记工作区继续新会话或需求revision不会因此新增工作区根。批量评测达到上限时保留旧home与证据，按上述配置器对全新home和另一端口创建同样的官方DS配置，再另行冻结；不删除旧记录或手改日志/AGH上限。新目录首次复现仍按上述独立home流程执行。

## 原生操作

打开http://127.0.0.1:4391/，新建工作区/会话，选择FitPlate面板。在会话使用通用方法Skill（.agh/skills/fitplate-design/SKILL.md），通过面板“用示例体验”载入公开输入，或点“填写我的安装要求”分四步填写实际需求和来源。核对后点“让 AI 检查这些要求”，按提示补充或修正输入；只有当前草稿 READY_TO_CONFIRM 且身份匹配时，才点击“确认条件，开始设计”，页面自动产生确认附件，无需手写JSON/hash。

未发送的填写只在本浏览器按会话恢复输入数据；卡片、确认、冻结和哈希不会恢复。恢复后必须重新检查、确认；发送成功或登记冻结后清除，七天过期或损坏的数据丢弃。更换浏览器不会带入草稿。

模型依次冻结任务、载入、建模、验证、按反馈修订、导出。权限卡逐次选择Allow once。设备中心在允许范围内由模型选择，用户固定事实不能擅改。查看当前版本的实测对象对、间隙与要求；展开G01–G08检查、版本列表，下载STEP/STL/报告。失败、阈值容差或未知结果不能当作通过。

带有 FitPlate 方法文件的产品工作区会在工具执行前限制通用写操作：shell、通用写入/编辑、代码执行、联网和子智能体调用会返回真实拒绝，模型应根据工具反馈改用 FitPlate 产品工具继续，不能把拒绝当成几何结论。普通工作区不启用此限制。AGH仍显示通用工具，必要只读查询沿用AGH既有权限；这不是完整文件系统或所有通道隔离的保证。

## 独立检查与复现产物

将下方目录替换为界面实际工作区/run/candidate/export路径，不使用开发目录旧产物。verify-cad重新读取实际STEP执行8项检查；verify-bundle检查交付绑定与文件清单。

```bash
PYTHONPATH=geometry .venv/bin/python scripts/verify-cad.py /absolute/path/workspace/runs/RUN/candidates/v001 --json
PYTHONPATH=geometry .venv/bin/python scripts/verify-bundle.py /absolute/path/workspace/runs/RUN/exports/v001/REPORT --json
PYTHONPATH=geometry .venv/bin/python scripts/reproduce-candidate.py --input-dir /absolute/path/workspace/input/intake-registry/tasks/TASK/r001 --design /absolute/path/workspace/runs/RUN/candidates/v001/design.json --out /absolute/path/new-rebuilt-candidate
```

重建输入目录必须包含实际冻结的task.json及其scene_ref引用的场景文件；原生表单冻结在input/intake-registry/tasks/TASK/r001目录，修订后按实际revision目录替换。设计文件取同一任务的实际候选design.json，输出目录必须尚不存在。此命令重建并复核工程产物，不替代原生模型流程验收；不能把未运行命令当作复现成功。公开示例examples/public-spec包含厂家规格与自设场景输入；initial-design教学解不在包内。

## 自动化浏览器依赖（人工浏览器操作可跳过）

```bash
PLAYWRIGHT_BROWSERS_PATH="$PWD/.cache/playwright" ./node_modules/.bin/playwright install chromium
node scripts/reproduction/fetch-browser-deps.mjs
export PLAYWRIGHT_BROWSERS_PATH="$PWD/.cache/playwright"
export LD_LIBRARY_PATH="$PWD/.cache/chromium-libs/usr/lib/x86_64-linux-gnu${LD_LIBRARY_PATH:+:$LD_LIBRARY_PATH}"
export FONTCONFIG_FILE="$PWD/.cache/native-fontconfig/fonts.conf"
```

该下载助手面向Ubuntu24.04/x86_64，通过apt-get download/dpkg-deb把所需库和中文字体解到新项目.cache，不使用sudo、不改系统包。其他发行版按Playwright提示安装系统依赖。缓存可删除后重装，不链接开发项目缓存。

## 可选自动化原生复现

自动化入口位于scripts/reproduction，不依赖开发目录、私有监督目录或参考答案。先按上文在新目录安装插件并启动4391，再准备自己的用户输入JSON文件。它只能包含id、text、form_fields或steps；form_fields键是面板的实际中文字段标签，值为字符串。例如下面只给需求和许可域，具体候选中心由模型选择：

```json
{
  "id": "public-reproduction",
  "text": "请在表单许可范围内设计并实际验证。",
  "form_fields": {
    "板宽": "120", "板高": "104", "板厚": "4",
    "孔 0 中心 X": "8", "孔 0 中心 Y": "8",
    "孔 1 中心 X": "112", "孔 1 中心 Y": "8",
    "孔 2 中心 X": "8", "孔 2 中心 Y": "96",
    "孔 3 中心 X": "112", "孔 3 中心 Y": "96",
    "移动许可": "y_range", "中心 X": "60",
    "Y 许可下限": "34", "Y 许可上限": "52",
    "固定柱 0 X": "20", "固定柱 0 Y": "84", "固定柱 0 半径": "4"
  }
}
```

这些是公开演示的自设输入，未实物测量；不是测试参考解。将JSON保存为新目录的request.json，先冻结，后运行：

```bash
"$AGH_SOURCE_ROOT/node_modules/.bin/tsx" scripts/reproduction/freeze-native-reproduction.mjs --input "$PWD/request.json" --out "$PWD/reproduction-protocol.json"
"$AGH_SOURCE_ROOT/node_modules/.bin/tsx" scripts/reproduction/native-reproduction.mjs --execute --protocol "$PWD/reproduction-protocol.json" --input "$PWD/request.json"
```

冻结器0模型调用，检查实际安装包、官方路由、高思考/1M声明、AGH提交与代码哈希，拒绝覆盖协议。驱动每次只跑一个输入，真实填写面板、整理需求；只有程序草稿可确认且模型本轮结束，才按事前约定点击确认，并逐次核对真实Allow once权限。缺失/冲突照实停止，不补提示或编造事实。每修订最多4个候选、每例300秒；所有首次失败保留，修改产品后必须另冻。输入中的expected、gold、solution等字段会拒绝；此字段检查不等于所有通道的答案隔离证明。

输出在runs/native-reproduction的新子目录，含result.json、实际浏览器录像、显式标明派生的公开文本/动作记录。公开记录只保留原始事件序号、显式text与必要动作元数据，省略私有思考和完整工具结果；不作为官方ZIP。实际产物仍在本次新工作区，须再运行上文8项STEP/31项交付检查，并在原生界面核对刷新、重载和下载。需要官方诊断ZIP时，从AGH原生界面另行导出并独立检查；官方导出可能含私有思考，公开分享前需明确生成去除该内容的派生副本。驱动退出码0/模型自然结束本身不代表完整交付通过。

## 关闭与内容边界

```bash
"$AGH_SOURCE_ROOT/node_modules/.bin/tsx" scripts/agh/web.mjs stop
"$AGH_SOURCE_ROOT/node_modules/.bin/tsx" scripts/agh/stop.mjs
```

pack-manifest.json列出包内逐文件bytes/SHA256。白名单包含产品源码、构建资产、schemas、设备卡、必要公开脚本/文档和通用Skill；不包含tests/fixtures、运行/日志、私有home、依赖缓存、监督评分或参考解。打包器与配置器可审阅。本文件提供安装和运行方法；测试结果见随附测试报告。
